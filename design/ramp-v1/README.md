# LGD Simulator · Ramp 方向 UI 样稿 v1

本目录是独立的设计评审样稿，尚未接入产品。

## 打开

直接用浏览器打开 `index.html`，或通过本地静态服务器访问。所有样式与脚本在本目录，无需安装依赖，不依赖外网字体或图片。浏览器地址锚点可使用 `#setup`、`#room`、`#report`、`#system`。

## 评审内容

1. 练习配置：群面四题型、题库题面、候选人；单面 2/3 人和六位原面试官。
2. 面试房间：群面与单面变体、字幕、侧栏、计时、语音控制和手机题目入口。
3. 评估报告：群面 8 维与单面 9 维、总分、权重、证据定位、建议、生成中及失败。
4. UI 规范：颜色、中文字体、组件、语义状态及设备检测示例。
5. 右上「手机预览」：以 390px 容器检查手机布局，再点「桌面预览」恢复。

顶部页面导航、宽度开关及报告状态切换仅属于评审工具，不添加到生产产品。演示数据均为虚构，不连接模型、数据库、硬件或钱包，不产生真实生成、录音、保存、删除、支付或交易。配置弹窗中不要填入真实密钥。

## 正式规范

见 `../../docs/superpowers/specs/2026-11-06-product-ui-design.md`。本轮不修改原有 App、业务组件、引擎、服务、接口、配置或部署。

## 检查记录

检查日期：2026-11-06。以下仅为独立样稿检查，不代表生产功能、真机权限或模型服务验证。

| 检查项 | 结果 |
|---|---|
| JS / CSS | `node --check prototype.js` 与 PostCSS 解析通过；不含 fetch、硬件采集、浏览器存储或交易调用 |
| 桌面 | 1280×720 检查三页；房间字幕与右侧栏独立滚动，无页面或侧栏横向溢出 |
| 手机 | 390×667 检查三页；360×640 检查三页无横向溢出；390 房间工具条底边约624.5px，360约597.2px，均在视口内 |
| 演示交互 | 群面/单面、2/3位选择及进入三面试官房间、设备状态/默认未同意、录音样式、证据定位、报告加载/失败/正常已检查 |
| 独立复核 | 无重要未决问题；已修正手机工具条高度、手机弹窗限宽及配置表单窄屏最小宽度 |

颜色计算：深字/荧光黄 16.02:1；辅助字/画布 4.72:1；控件边界/白底 3.37:1、控件边界/画布 3.01:1；成功、警告、危险的前景/底色均大于4.5:1。这里只验证这些令牌配对，未进行完整 WCAG 审计。
